## 本地数据与工具（克隆库内）

- `data/`：实体/配怪/尺寸等测量与目录数据
- `src/qxfmt/`：容器读写、模板合成、规则校验（社区工具，非本仓维护）
- `templates/`、`examples/`：示例图与 BOM 样本

使用对方 Python 工具前读其 `QUICKSTART.md` 与 `pyproject.toml`；本仓不强制安装。
