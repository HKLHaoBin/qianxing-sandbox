# 客户端 Lua 硬规则摘要（摘自需求档案 v3.1）

完整条文以档案 `AGENT.md`「不可省略的规则」及对应 `prompts/` 为准。此处只留写码时最常踩的坑。

## 语言与宿主

- 只用文档支持的 **Lua 5.3** 能力；不用 `io.*`、`coroutine.*`、`string.dump`；`os` / `debug` 仅限 API 文档允许的成员。
- 优先 `local`；避免无界循环和未声明的宿主全局。

## 编号不要混用

下列用途不同，**不能互换**：

容器节点索引 · 控件模板索引 · 运行时 `id` · 图片 `imageId` · 脚本映射 ID · 网格 `itemPrefabIndex` · 模板引用 `referencedPrefabIndex`

已有实例优先按 **名称 / 相对路径 / 对象引用** 取得；模板索引只在文档和工程都明确时用于创建或身份核对。合法的 `0` 可以是位置/角度/透明度，不要把所有零当成「未填」。

## 按钮按结构命名

- **组合式按钮**：容器节点 + 图片/文本框 + 光标检测区域（自定义交互优先）。
- **预设按钮**：`ClientUIPresetButtonControl`；需要编辑器四态、按键样式或点击音效时才用。
- 不要用「动态/静态」区分二者；需要换图或 Tween 不必然重写预设按钮。
- 预设按钮本体 **没有** 图片/文本/颜色专有字段；外观来自子级。空外观仍可能被点中——**不能用点击证明已显示**。详见档案 `docs/08`、`docs/10`。

## 网格与 Instantiate

列表项：`itemPrefabIndex` + `RefreshItems`。  
普通面板 / 拖拽幽灵：`InstantiateClientUIControl`。  
不要把普通实例硬塞进网格。

## Tween 与写入权

- 只补间 API 标注可 Tween 的字段；先设起点再创建 Tween。
- 同一字段保持 **单一写入者**；取消用 `Kill(false)`。
- 纯 Tween 不为了计时去开逐帧。

## 生命周期与资源

- 不假定文档未声明的精确启动顺序；启动/清理应可安全重复。
- 停用：关本脚本输入与更新、注销自有监听、停动画/任务；按策略保留或释放自有控件。
- 再次启用明确：继续 / 重播 / 重建 / 等待触发。
- **每个资源一个拥有者**；借用宿主/他人控件不销毁；注销用注册时保存的原回调。
- 先停回调来源再销毁；延迟回调检查对象仍存活且本轮任务仍有效。

## 配置与错误

- 用户可调参数与资源候选进 `CONFIG`；运行中的对象、句柄、计时进独立状态。
- ID 占位不得传入宿主调用。
- 错误不能静默吞掉；`pcall` 未抛错 ≠ 业务成功。日志带前缀、去重，不逐帧刷屏。

## 证据分层

静态/模拟检查与客户端运行观察分开写。未做的检查不写「通过」；模拟通过不写「真机通过」。详见档案 `docs/07`、`docs/05`。

## 坐标

跨父级、拖拽、分辨率换算先读档案 `prompts/60_坐标.md`，不要猜。
