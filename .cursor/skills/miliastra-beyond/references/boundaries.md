# 能力边界与导出

与上游 README「当前支持边界」一致；有冲突以上游与本机包行为为准。

## 必须管住的预期

- **模拟器通过 ≠ 真机通过。** 用于提前发现脚本、布局、交互问题；最终在千星奇域验证。
- **服务端只薄模拟变量与信号。** 1–8 人是本地多客户端；不包含完整官方服务端节点图或真实联机。
- **图片以基础图元代理为主。** 常见代理 ID `100001–100006`；完整官方图/动效不在装包内，缺失会有提示。
- **GIA 仅已验证子集。** 部分控件属性与脚本挂载无法完整往返；导出看警告，**JSON 存档当真源**，并保留原始 GIA。

## 存档与导出怎么选

| 目的 | 推荐 |
|------|------|
| 继续开发 / 交给 AI | 完整存档包 JSON（三类资产合一） |
| 与官方编辑器交换已支持部分 | 导出对应 GIA，导入后目视核对 |
| 单改脚本 | 导出单个 Lua 或脚本包 |
| 无损工程字段 | Authoring JSON（以编辑器选项名为准） |

编辑与试玩**不会**自动把完整存档写入磁盘。

## 和本仓库其他技能的边界

| 事项 | 技能 |
|------|------|
| 是否该用 Lua | `miliastra-lua` |
| API / 模板 / 写码硬规则 | `miliastra-lua` → 需求档案 v3.1（authoring-pack） |
| 在模拟器里做与测 | **本技能 `miliastra-beyond`** |
| 改服务端节点图五要素 | `miliastra-node-edit` |
| 查官方节点/系统文档 | `miliastra-knowledge` |
| 整局原件清单 | `miliastra-brief`（UI 项标「优先 Lua + beyond」；复杂 HUD 可注档案模板号） |
