# 千星沙箱模拟器（Beyond）

面向 **7.1 客户端 Lua + 客户端控件** 的外置开发工具。在浏览器或 AI（MCP）里编辑 UI、跑 Lua、试玩与截图，不必每次打开官方编辑器或真机。

上游开源仓库：[1475505/miliastra-beyond-simulator](https://github.com/1475505/miliastra-beyond-simulator)（GPL-3.0）。本方法论仓库通过 npm 包接入，不嵌其 Git 历史。

协作者的 AI 应读：`.cursor/skills/miliastra-beyond/SKILL.md`。  
**约定：需要写 Lua 时，优先用本模拟器开发与自测，再导出到千星奇域做真机验证。**

## 怎么装

```powershell
.\scripts\setup.ps1
```

会安装全局命令 `beyond-simulator-web`、`beyond-simulator-mcp`，并创建本机目录 `beyond-workspace/`。

Cursor MCP：把 `tools/beyond-simulator/mcp.json.example` 拷进你的 MCP 配置，把 workspace 改成 `beyond-workspace` 的绝对路径，然后重启。

仅开 Web：

```powershell
beyond-simulator-web --workspace "<本仓库>\beyond-workspace" --open
```

## 开发节奏（人话）

1. 在模拟器里搭客户端控件、写 Lua  
2. 试玩、看日志/截图；能自动的让 AI 用 MCP 点按与断言  
3. 保存 `.save.json`  
4. 导出已支持的 GIA（注意警告），进官方编辑器 / 真机核对  
5. 真机问题回到模拟器修，再导出  

模拟器通过 ≠ 真机通过。服务端节点图权威逻辑仍按原技能链做。
