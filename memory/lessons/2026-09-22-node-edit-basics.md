# 编辑器手法

这些是下一局还会用到的做法。某一局的元件 ID 和关卡流程不写在这里。

## 全局计时器控件

未启动的全局计时器，界面固定显示 `00:00`。要开局就显示满时长、准备阶段不往下走：`启动全局计时器` 然后 `暂停全局计时器`，阶段到了用 `恢复全局计时器`，不要再次启动。

多个计时器控件叠在一起时，先查谁还可见，再查计时逻辑。准备走完后若准备控件没隐藏，屏幕上的 `00:00` 可能是准备控件。

## 节点真名

显隐用 `设置界面控件(组)状态`。列表循环的节点名是 `列表迭代循环`。它的脚：入是开始、跳出循环、迭代列表；出是循环体、循环完成、迭代值。

## 新建节点的搜索 ID

编辑器先填空号（删过或没用过的 index），空号用尽才用最高 ID+1。同一批新建按创建顺序吃掉最小空号。说明里写推算 ID；和导出冲突时以导出为准。

## 两个元件

两套逻辑不要共用同一条「获取场上指定元件ID的实体」。运动目标和状态标记要各拿各的实体。

## 枚举

显示状态：1901=开启，1902=隐藏。结算：4101=胜利，4102=失败。
